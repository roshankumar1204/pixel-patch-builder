      About this tool

      Rizhu Pixel Patch Builder is a free LED pixel mapping and DMX patch tool for lighting designers, installers and VJs. Draw LED matrices, pixel strips, rings, arcs, window frames and LED text, trace any shape, or import SVG logos, images and LED point lists. Every pixel gets its DMX universe and channel automatically (RGB, RGBW and more, snake wiring, controller ports), and you export a CSV fixture list for MADRIX 5 plus a wiring sheet for the installation.

      It runs in the browser on Windows, macOS, Linux and phones, needs no install or account, and works offline.

      Import into MADRIX 5

      1. Patch Editor → File → Import Fixture List…
      2. Choose the CSV, tick Use Header Line (1 line), separator as set above.
      3. Assign columns: Position X/Y/Z, DMX Universe, DMX Channel. Pick a matching pixel fixture from the library.
      4. Finish – the whole layout is patched.
